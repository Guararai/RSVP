# RSVP Reader ⚡📖

**Leitura dinâmica direto no navegador — uma palavra de cada vez.**

> **RSVP** (*Rapid Serial Visual Presentation*) é uma técnica de leitura rápida que exibe palavras uma a uma em sequência, eliminando o movimento dos olhos e permitindo velocidades de leitura muito superiores à leitura convencional.

🔗 **[Experimente agora](https://guararai.github.io/RSVP/)**

---

## O que é?

Uma aplicação web standalone (um único arquivo HTML — zero dependências) que transforma qualquer texto em uma experiência de leitura dinâmica. Cole um artigo, um capítulo de livro, ou qualquer texto e leia de 100 a 1000 palavras por minuto.


## Tech

HTML + CSS + JavaScript vanilla. Sem frameworks, sem build, sem servidor. Abre e usa.
